## 🏢 About Us

**Thenam Software Solutions** is a next-generation **AI-first product studio** designing and shipping software, automation and IoT systems for ambitious teams worldwide. Founded in **2025** in **Chennai, India**, we build category-defining software and intelligent ecosystems.

> *"Software is becoming intelligent, ambient and deeply personal. The teams that ship the next decade of products will be those that combine taste, engineering and AI fluency. We built Thenam to be one of them."*

### 🎯 Operating Principles

| Principle | Philosophy |
|-----------|-----------|
| **Craft** | The work is the brand. Every pixel, every API, every interaction. |
| **Clarity** | Calm design. Honest writing. Clear pricing. Clear contracts. |
| **Compounding** | We build platforms, not projects. Leverage compounds when the system is clean. |
| **Curiosity** | Research is not a phase. It's how we work, every week. |
| **Care** | For users, for each other, for the long arc of the work. |
| **Courage** | We take the harder, better path — and ship it. |
